# 枝桠 Zhiya · 使用说明

> 一个思维导图工具。绿色免安装，文件格式与 Xmind 双向兼容。

枝桠是对 Xmind (v25) 逆向研究的复刻作品：结构引擎、主题、标记、概要、备注等均按 Xmind 的真实数据格式实现——**你导出的 `.xmind` 文件可以直接用 Xmind 打开，Xmind 的文件也可以直接拖进来**。

---

## 一、开始使用

1. **解压** zip 到任意位置（桌面、D 盘、U 盘均可）
2. **双击「启动枝桠.bat」**——浏览器自动打开，就是完整版

启动后会保留一个黑色控制台窗口，**关闭它 = 退出枝桠**（最小化不影响使用）。

### 为什么建议用启动器？

| | 双击 启动枝桠.bat（推荐） | 直接双击 枝桠.html |
|---|---|---|
| 附件（附加的文件） | ✅ 跨刷新保存 | ❌ 刷新后需重新附加 |
| 保存 `.xmind` | ✅ 原生对话框，Ctrl+S 直接写回文件 | ⚠️ 走浏览器下载 |
| 安装成独立应用 | ✅ 可安装（见下） | ❌ |
| 免启动器/拷给他人 | — | ✅ 单文件即可分享 |

> macOS / Linux：双击或运行「启动枝桠.command」（需系统自带 python3）。

### 安装成独立窗口应用（可选）

用启动器打开后，在 Edge/Chrome 地址栏右侧点「安装应用」——获得无地址栏的独立窗口，可固定到任务栏。安装后可关闭黑色控制台窗口（应用将直接从浏览器本地运行）。

## 二、你的数据保存在哪

| 内容 | 保存位置 | 说明 |
|---|---|---|
| 导图内容 | 浏览器自动保存（每次修改后约 0.5 秒） | 重开浏览器自动恢复 |
| 持久备份 | `Ctrl+S` 导出 `.xmind` 文件 | **这是真正的文档**，请养成习惯 |
| 附件 | 浏览器数据库（启动器模式下跨刷新保存） | 随 `.xmind` 导出时嵌入文件内 |

**重要**：数据存在**浏览器**里，不是存在解压的文件夹里——文件夹可以随意移动、删除、升级替换，都不影响你的导图；但**清除浏览器数据会丢失自动保存的内容**，且换一个浏览器打开看不到之前的图。跨设备/长期保存靠 `Ctrl+S` 导出的 `.xmind` 文件。

## 三、常见问题

- **双击 bat 后窗口一闪而过？** 确认 `zhiya-server.ps1` 和 `枝桠.html` 与启动器在同一目录（不要单独拷出 bat）。
- **系统提示"已保护你的电脑"？** 来自网络的 zip 首次运行可能触发 SmartScreen——点「更多信息」→「仍要运行」即可（本包仅在本机 127.0.0.1 提供页面，不访问网络）。
- **端口被占用？** 启动器自动从 8765 起找空闲端口，无需处理。
- **怎么彻底退出？** 关闭黑色控制台窗口。
- **浏览器没自动打开？** 手动访问控制台窗口里显示的地址（如 `http://127.0.0.1:8765/`）。

## 四、核心操作速查

| 操作 | 方式 |
|---|---|
| 添加子主题 / 同级 | `Tab` / `Enter` |
| 重命名 | 双击 或 `F2` |
| 折叠 / 展开 | `Space` 或点折叠指示器 |
| 删除 | `Delete` |
| 导航 | 方向键（自动感知分支方向） |
| 调序 / 换父 / 转自由主题 | 直接拖主题（拖到空白处 = 自由主题） |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 查找替换（标题/备注/标签） | `Ctrl+F` |
| 多选批量（删除/样式/标记） | `Ctrl+左键` 加选，`Ctrl+D` 取消 |
| 演示模式（逐分支聚焦） | `F5`，`→`/`空格` 步进，`Esc` 退出 |
| 备注 | `Ctrl+M` 或点主题角标 |
| 联系（两主题连线） | 右键 → 添加联系到… → 点目标 |
| 图片 / 附件 / 链接 | 右键主题 → 插入图片… / 附加文件… / 设置链接… |
| 标记 / 标签 / 形状 / 主题 | 右键 → 标记 / 样式（侧栏） |
| 概要（可改名、拖端点调范围） | 右键 → 添加概要 |
| 分支方向 | 右键 → 分支方向（思维导图结构下） |
| 图例 | 文件菜单 → 图例 |
| 缩放 | 滚轮 / 双指捏合；触屏长按 = 右键菜单 |

**结构**：工具栏下拉提供 27 种（思维导图/逻辑图/发散图/组织架构/鱼骨图/时间轴全系/树图/括号图/树表格/矩阵/电子表格），画布内可随时切换。
**主题**：侧栏样式页提供 47 款（43 款移植自 Xmind 官方，含暗色系），支持导入 Xmind 主题文件。
**导出**：PNG（可加水印）/ SVG / Markdown / OPML / FreeMind / Word / Excel / PPT / TextBundle / 大纲文本 / PDF（打印）；右键主题可只导出某分支。
